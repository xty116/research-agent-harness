# 验证范围与已知限制

验证日期：2026-11-01。本仓库只保留可复现的测试与合成例子；真实运行数据库、原文和私人账单不发布。

## 工程验证

- Ruff 静态检查通过。
- 52 项离线回归覆盖：证据版本与引文完整性、断言修订、任务状态、有限补查、预算预占与未知计费、跨日额度、租约与恢复、SSRF/重定向边界、浏览器控件门禁、来源日期过滤、上下文裁剪与强弱路由。
- 报告回归覆盖：超过 100 次历史运行的分页检索；终态补报不改 checkpoint/status/usage；四种导出；真实/合成隔离；事件游标；不可变原文版本；HTML/Markdown 转义及不安全链接；只读 HTTP 行为。
- 浏览器人工自动化验收：1440×1000 桌面与 390×844 手机视口，导航展开、报告阅读、筛选空状态、Markdown 复制及执行轨迹。仓库截图全部为明确标记的演示环境。
- Python 3.12 与 3.14 均用于本地回归。macOS launchd 在运行副本启动服务，读取同一份预算账本。

CI 只进行离线验证，不保存密钥，不将确定性演示作为真实 Agent 能力评测。

## 小额真实联调已经确认的部分

| 范围 | 观察 | 不能推出的结论 |
| --- | --- | --- |
| 来源连接 | 论文、GitHub、HuggingFace、RSS 取得过真实材料；Tavily 返回过 HTTP 432 额度错误 | 未通过完整五通道线上日报验收 |
| 模型路由 | 已发送显式 thinking enabled/disabled 请求；记录请求别名与实际返回名 | 不保证别名永远对应不同参数规模 |
| 原子断言语义回归 | 4 个合成标注案例调用真实模型，通过 4/4 | 不是调研准确率或统计充分的模型评估 |
| 单任务闭环 | 预设真实论文缓存问题，经模型选择取证和断言评估后完成该任务 | 不是自然发现能力或完整四方向交付 |
| 本地向量 | Qwen3 量化模型生成 1024 维向量，跨语言查询召回过目标材料 | 不是完整召回质量基准 |
| 日报质量 | 部分完整执行因信源缺失、预算或 Critic 问题保持 partial | 不将部分成功表述为稳定高质量日报 |

一次联调中，两种请求别名均返回 `deepseek-flash`；程序保存实际返回模型名，这里不把未调用的其他模型写成已集成。

## 已知限制

1. 全网来源依赖 Tavily 额度，配置有 Key 不等于有可用余额。额度恢复前保留失败与缺口，不伪造完整交付。
2. 引文匹配只能验证文字存在，不能证明推论充分。模型与 Critic 均可能犯错，关键结论应人工复核。
3. 固定步数、时间和预算约束会导致部分交付。自动重试有上限，外部动作是至少一次执行，不保证恰好一次。
4. 费用是配置费率估算；未知请求保留预占，实际账单以供应商为准。
5. 默认无公网鉴权；看板仅适合本地只读。没有远程多用户、消息推送、采购、任意代码执行或远程 Skill 安装。
6. 本地常驻依赖用户会话与电脑运行，不能在关机时执行。未启用自动审计数据清理，需人工关注磁盘与日志。
7. 自动化测试不包含所有真实网页结构变化、供应商故障或完整长期研究质量。需要持续扩充经人工标注的真实评测集。
