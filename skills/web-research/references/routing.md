# Source routing

- Benchmark/method: find the paper, official leaderboard and evaluation setup.
- Repository capability: read the actual README, release or implementation page via fetch_page. Stars are not validation.
- Personnel: use public authored papers or official team announcements. Preserve identity ambiguity.
- Supplier: seek the official offering, documentation and dated partnership. A news mention does not establish data quality or availability.
- Recent-event collection uses the run window. Older primary material may establish background, with its date stated explicitly.

The tool interface adapts the search-then-extract practice documented by Tavily: https://github.com/tavily-ai/skills . This project uses typed Python tools rather than shell commands.
