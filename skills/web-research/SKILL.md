---
name: web-research
description: Discover web, scholarly or repository sources and read selected originals, including dynamic pages.
allowed-tools: search_web search_papers search_github fetch_page read_paper read_document find_in_document browser_read
---
Search narrowly, then fetch the best original pages. Prefer a known source over another broad search. Repository metadata establishes discovery, not implementation behavior. Use read_paper for HF paper Markdown. Use browser_read only if rendered controls are necessary. Missing content is a gap, not negative evidence. Keep source IDs with each fact; use read_document when an excerpt was compacted out. For source-specific routing read references/routing.md.

For a long paper, use find_in_document for an exact term or number and read_document with an empty focus and offset for adjacent sections. Stop repeated retrieval when it yields no new evidence; assess what is available or defer the missing field.
