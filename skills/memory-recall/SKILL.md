Search by entity and question before creating duplicate work. Treat recalled conclusions as dated context. Recheck time-sensitive facts using current originals. Bring new evidence to an open question; preserve both old and new assessments. Use source IDs for retrieval, not an uncited recollection. A prior unverified result means unresolved, not false. Defer repeated dead ends until a new signal or the retry date.
