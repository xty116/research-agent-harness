---
name: benchmark-verification
description: Verify model or dataset performance claims with matched versions, metrics and leaderboard scope.
allowed-tools: read_document find_in_document
---
Match model version, benchmark version, test split, metric, evaluation setup, leaderboard category and result date. A subset or open-model rank is not an overall rank. Separate paper claims from independently reproduced results. Record which required fields are absent; use unverified for a broader claim when scope is missing. Read references/comparison.md for conflicts. Pair with evidence-review to assess a claim.
